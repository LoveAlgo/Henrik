# henrikhillerstrom.com

Personal website of Henrik Hillerström. Built with Jekyll, hosted on GitHub Pages, edited with Pages CMS.

## Where things live

- `index.md`: Home page text (edit in Pages CMS under "Home page")
- `about.md`: About page (Pages CMS: "About page")
- `_projects/`: one file per project (Pages CMS: "Projects"). The `order` field sets the position on the home page.
- `_data/contact.yml`: email, WhatsApp, LinkedIn (Pages CMS: "Contact details")
- `assets/images/`: all images (Pages CMS: "Media")
- `assets/css/style.css`: colours, fonts and layout
- `CNAME`: the custom domain, www.henrikhillerstrom.com

## Adding a project

In Pages CMS, open Projects and add an entry. Its page appears at `/file-name/` and on the home page automatically.
